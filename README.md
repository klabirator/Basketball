# 🏀 Снайпер — тренировка бросков

Веб-приложение для телефона: камера **сама находит кольцо, отслеживает мяч и считает попадания и промахи**, без ручной разметки. Во время тренировки экран трогать не нужно: громкие звуки, голос и крупные цифры сообщают результат.

Работает прямо в браузере (Chrome на Android, Safari на iOS), ставится на главный экран как приложение (PWA), после первого открытия работает офлайн. Все данные хранятся только на телефоне.

## Возможности

- **Автопоиск кольца** в два шага. Сначала по форме, цвет обода не важен: под ободом ищется сетка с ромбовидным плетением, над ним щит стандартных пропорций; предпочтение отдаётся верхней части кадра. Если уверенного результата нет, учитывается цветовое подтверждение: изолированная красная разметка у кольца (обод, квадрат на щите, кронштейн). Сплошные оранжевые поверхности (пол, панели, покрытие) за кольцо не принимаются. Поиск идёт на пирамиде масштабов в фоновом потоке по кадру, усреднённому во времени. Ширина кольца, не подтверждённая щитом, уточняется по размеру летящего мяча (диаметр мяча равен 0,52 ширины кольца). Если автопоиск ошибся или не справился, нажмите ◎ и коснитесь кольца.
- **Движущаяся камера**: если весь кадр «плывёт», приложение предупреждает, сбрасывает кольцо и не считает броски. Рассчитано на неподвижный телефон.
- **Отслеживание мяча**: вычитание фона, мяч узнаётся по размеру (≈ половина ширины кольца), форме и цвету. Ведётся несколько треков с прогнозом по скорости и гравитации. Если мяч ненадолго скрылся за кольцом или щитом, трек подхватывается снова.
- **Попадание или промах**: попадание засчитывается, когда мяч сверху вниз прошёл через обод и ушёл вниз, не выпрыгнув обратно и не уйдя в сторону. Если мяч потерялся в сетке, помогает анализ движения сетки. Отскок от дужки, промах мимо кольца и «воздух» считаются промахами.
- **Несколько игроков у одного кольца**: одновременно ведётся несколько бросков, каждый привязан к своему мячу (с прогнозом по скорости и гравитации), поэтому мячи в воздухе не путаются; игроки на подборе, ведение мяча и передачи ниже кольца бросками не считаются. Счёт при этом общий на всех: кто именно бросал, приложение не различает.
- **Приближение**: аппаратный зум камеры (если доступен) плюс цифровой до 4×. Кнопки −/+, щипок двумя пальцами, перетаскивание кадра. Двойной тап или кнопка с текущим зумом включают авто-зум на кольцо. Авто-приближение срабатывает и само, когда кольцо мелкое.
- **Громкие разные звуки**: попадание и промах звучат по-разному, есть 3 набора («Классика», «Аркада», «Стадион»). Звук идёт через компрессор и усиление, поэтому громкий. За серии 3, 5, 10… играют фанфары.
- **Без касаний**: голосом озвучивается счёт (после каждого броска или каждые 5 или 10). Работают голосовые команды «пауза», «продолжить», «отмена», «попал», «мимо», «счёт», «закончить», «приблизить». Экран не гаснет. После нахождения кольца есть 5 с, чтобы встать на позицию.
- **Режимы**: свободный, на количество бросков, на время (голос предупреждает за минуту и за 10 с), по точкам (5 точек на средней или трёхочковой дистанции, штрафные, ближние, «вокруг света»). По точкам голос называет следующую позицию, на переход даётся 8 с.
- **Статистика**: попадания/броски, процент точности, текущая серия, последние 10 бросков, таймер.
- **Проверка на видео**: кнопка «🎬 Проверить на видео» прогоняет любой ролик (MP4/WebM из галереи) через то же распознавание, что и камера. Можно поставить на паузу, перемотать, сменить скорость (0.5×/1×/2×), включить отладку в настройках. В отчёте видно, в какой секунде ролика засчитано попадание или промах. Перед воспроизведением приложение просматривает ролик и пытается найти кольцо заранее, чтобы считать с первой секунды. Такие прогоны в историю не сохраняются.
- **Ручная коррекция**: ✓ или ✗ добавляют бросок, ↶ отменяет последний.
- **История**: точность за всё время, за 7 и за 30 дней, рекорды, график прогресса по тренировкам или дням с трендом, детализация по точкам, сравнение первой и второй половины тренировки, экспорт в JSON и CSV, импорт.

## Как поставить камеру

1. Сбоку под углом около 45° к щиту, в 4–8 м от кольца, на штативе или опоре.
2. Кольцо в верхней половине кадра, над ним видно 2–3 м для дуги мяча.
3. Кольцо должно занимать не меньше 1/15 ширины кадра, иначе приблизьте.

## Запуск

Камера в браузере работает только по **HTTPS** (или на `localhost`).

- **GitHub Pages**: Settings → Pages → Deploy from a branch → выберите ветку и папку `/ (root)`. Откройте ссылку на телефоне и выберите «Добавить на главный экран».
- **Локально**: `npm run serve` (или `python3 -m http.server 8080`), затем откройте `http://localhost:8080`.

Сборка не нужна: чистые HTML, CSS и JS-модули, без зависимостей.

## Android-приложение (APK)

Папка `android/` — нативная оболочка: веб-приложение из корня репозитория при сборке копируется внутрь APK
и открывается через WebView по безопасному адресу (камера работает без интернета).
Добавлено то, чего нет в WebView: озвучка через системный синтез речи Android, сохранение экспорта
в «Загрузки», «Поделиться», экран не гаснет, полноэкранный режим, кнопка «Назад».
Голосовые команды в APK недоступны (WebView не поддерживает распознавание речи).

Сборка (нужны JDK 17+ и Android SDK, путь к SDK — в `android/local.properties` или `ANDROID_HOME`):

```bash
cd android
./gradlew assembleRelease
# → android/app/build/outputs/apk/release/app-release.apk
```

APK подписан отладочным ключом — его можно сразу установить, но для Google Play нужен свой ключ.
Установка на телефон: скопируйте APK, откройте его и разрешите установку из этого источника.

## Тесты

```bash
npm test        # детектор на синтетических сценах: поиск кольца, попадания/промахи, шум, портрет,
                # групповая тренировка (test/crowd.mjs — несколько мячей, подбор, ведение; сверка с эталоном)
npm run e2e     # всё приложение в Chromium с фейковой камерой (нужен playwright)
```

## Структура

| Файл | Назначение |
|---|---|
| `js/detector.js` | компьютерное зрение: мяч, логика броска, сопровождение кольца |
| `js/rimfinder.js`, `js/rimworker.js` | поиск кольца по форме (сетка + щит), фоновый поток |
| `js/app.js` | экраны, тренировка, зум, жесты, события |
| `js/camera.js` | камера и аппаратный зум |
| `js/audio.js` | синтез громких звуков |
| `js/voice.js` | озвучка и голосовые команды |
| `js/storage.js`, `js/history.js` | хранение, статистика, история и графики |
| `sw.js`, `manifest.webmanifest` | офлайн-режим и установка как приложения |
